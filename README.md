# Analyze E-Commerce Sales to Improve Customer Conversion & Retention

## Project Overview

This project explores e-commerce sales and customer behaviour to identify patterns that can help a business improve sales performance, customer experience, conversion, and retention. It brings together data analysis, SQL queries, dashboards, and project documentation.

## Objectives

- Explore sales and customer data to identify meaningful patterns and trends.
- Examine purchasing behaviour and indicators related to repeat purchases and customer retention.
- Review order and delivery performance where the available data supports it.
- Present findings through analytical reports and dashboards.
- Demonstrate an end-to-end data analytics workflow using Python, SQL, Excel, and Power BI.

## Tools & Technologies

- **Python** — exploratory data analysis (EDA) and notebook-based analysis
- **SQL** — querying and analysing data
- **Microsoft Excel** — dashboard and reporting
- **Power BI** — interactive business intelligence dashboard
- **Jupyter Notebook** — documenting and running analysis

## Key Areas of Analysis

- Sales trends and business performance
- Customer purchasing behaviour
- Repeat purchasing and retention patterns
- Order and delivery performance, where supported by the data
- Business questions and hypotheses explored through analysis
- Dashboard-based reporting of key findings

## How to Explore the Project

1. Start with the business objectives and hypotheses in `Phase-3/`.
2. Review the Python EDA notebook and report in `Phase-5/`.
3. Explore the SQL queries in `Phase-6/Phase-6_Project.sql`.
4. Open the Power BI file in `Phase-7/` using Microsoft Power BI Desktop.
5. Review the additional analysis and final reports in the later phase folders.

### Requirements

- Python 3 and Jupyter Notebook to run the Python notebooks
- A SQL environment compatible with the queries in the SQL file
- Microsoft Excel to open the Excel dashboard, if included
- Microsoft Power BI Desktop to open the `.pbix` report
